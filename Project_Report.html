1. Problem Statement

1.1 Context & Background

Varendra University (VU) has shifted its primary academic activities to its permanent campus located at Kharkhari, Rajshahi, situated along the northern-eastern bypass corridor. Consequently, students, professors, and administrative staff commute daily from various residential, commercial, and transit zones across Rajshahi City—such as Zero Point, Alupatti, Laxmipur, Railgate, Bhadra, Talaimari, Kazla, Binodpur, Katakhali, Choddopai, Shalbagan, and Naodapara.

1.2 The Problem to Solve

A student's priority changes depending on their situation:

  • Fastest Route ("Taratari jawa jabe"): During morning exams or tight lecture schedules, students prioritize minimizing travel time, taking direct express bypass corridors.
  • Cheapest Route ("Vara kom lagbe"): On normal days, students on a limited monthly budget prefer lower fares via shared local student tempos and inner hops, saving valuable pocket money.

2. Algorithm of the Solution

1. Represent the road network as an undirected graph G = (V, E).
   - Vertices (V): Rajshahi hubs (Katakhali, Talaimari, Binodpur, VU, etc.)
   - Edges (E): Direct road connections with dual weights: {fare, time}.

2. Input starting location and priority (1 = Cheapest Route, 2 = Fastest Route).
   Target destination is fixed to "Varendra University (VU)".

3. Initialize minCost array with INFINITY, parent array with -1.
   Set minCost[startNode] = 0 and push (0, startNode) to Min-Priority Queue.

4. While PQ is not empty:
   a. Pop node 'u' with minimum cost.
   b. If u == endNode, break.
   c. For each neighbor edge (u -> v):
        weight = (priority == 1) ? edge.fare : edge.time
        If minCost[u] + weight < minCost[v]:
            minCost[v] = minCost[u] + weight
            parent[v] = u
            Push (minCost[v], v) to PQ.

5. Reconstruct the optimal path by backtracking from endNode using parent[] array.
6. Calculate total fare and total travel time along the path and display the step-by-step route.

5. Discussion

5.1 Time and Space Complexity

Metric Complexity Explanation
Time Complexity O((V + E) log V) Min-heap priority queue extracts minimum cost vertices and relaxes edges in logarithmic time. Execution finishes in < 1 ms.
Space Complexity O(V + E) Adjacency list stores graph nodes and edges with linear memory footprint.

5.2 Technical Challenges

  • Resolving Node Mapping: Ensuring that location aliases and string inputs consistently map to the exact destination node ID to prevent unintended default-constructed node traversals.
  • Dual-Criteria Calibration: Decoupling fare and travel time so that local shared tempo hops minimize monetary expenditure while direct express bypass corridors minimize travel duration.
